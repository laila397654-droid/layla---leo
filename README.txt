# Layla Love Lelooo

## الملفات
- `index.html` = الموقع
- `style.css` = التصميم والألوان والأنيميشن
- `script.js` = الحركة ومشغل الصوت
- `song.mp3` = ضعي هنا ملف الصوت الذي تريدين تشغيله

## تشغيل الموقع على GitHub Pages
1. ارفعي الملفات الأربعة إلى نفس الـ repository.
2. مهم جدًا: اسم ملف الصوت يكون بالضبط `song.mp3`.
3. من Settings > Pages اختاري Deploy from a branch ثم `main` و `/root`.
4. احفظي الإعدادات وانتظري نشر الموقع.

ملاحظة: لا تضعي كلمات الأغنية المحمية داخل الموقع. المشغل يشغّل ملف الصوت نفسه، والنص الموجود تحته هو الجملة الخاصة بالموقع.
